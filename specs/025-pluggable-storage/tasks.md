## Implementation Strategy

MVP = Phase 1+2+US2（SQLite 用户面零破坏的 Flyway 收编——即使 PG 面延后，收编本身已还清演进债）；随后 US1 交付 PG 部署选项，US3 补演进与并发保障。T011/T014/T022 三个 checkpoint 各自可停可验。
